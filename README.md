## Overview
💪 GYM Website (CSS3 Project) This is a static GYM website built using HTML5 and CSS3. The main focus of this project is to demonstrate advanced CSS3 techniques, including: 
🎯 CSS Transforms 🎞️ CSS Animations 📦 Flexbox Layout 🔲 CSS Grid ⚠️ Note: This project is not responsive and is best viewed on desktop screens. purely HTML and CSS.

- **HTML5 | CSS3**
- **Font Awesome** for icons
